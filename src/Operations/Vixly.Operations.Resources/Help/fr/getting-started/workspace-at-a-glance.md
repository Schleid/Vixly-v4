Votre espace rassemble le travail que vous effectuez pour {brandName}. Utilisez la navigation pour atteindre les tâches accessibles à votre compte. La page d’accueil peut afficher du travail en attente, des raccourcis et des tâches de configuration pour les responsables de l’entreprise.

Le portail client à l’adresse {portalAddress} est un espace distinct où les clients suivent leurs propres activités avec l’entreprise. Continuez le travail du personnel dans cet espace plutôt que de considérer le portail client comme un autre menu du personnel.

## Étapes
1. Ouvrez **Accueil** pour revenir à l’accueil. Vérifiez le nom de l’entreprise avant de saisir des informations.
2. Choisissez une tâche dans la navigation ou un raccourci disponible. Les choix dépendent de vos responsabilités.
3. Consultez les compteurs de travail en attente affichés. Ouvrez le compteur pertinent pour consulter sa liste ; un nombre ne représente pas une tâche terminée.
4. Ouvrez **Aide** pour trouver des instructions ou utilisez le point d’interrogation de l’en-tête pour la page actuelle.

## Et ensuite
Ouvrir une page ne termine pas les tâches affichées. Suivez les instructions de l’écran concerné et vérifiez le résultat. Gardez votre compte privé et déconnectez-vous lorsque vous avez terminé sur un poste partagé.
