Votre invitation vous permet de travailler pour {brandName}. Utilisez le lien qui vous a été envoyé et créez votre propre accès. Gardez ce lien privé : il est destiné à la personne invitée.

Les étapes affichées dépendent des exigences de connexion de l’entreprise et de l’état de cet appareil. Terminez les vérifications demandées avant de vous attendre à accéder à l’espace de travail.

## Étapes
1. Ouvrez le lien d’invitation et vérifiez qu’il concerne la bonne entreprise. Lisez la page avant de saisir un mot de passe.
2. Renseignez **Nouveau mot de passe** et choisissez **Continuer**. Utilisez un mot de passe que vous pouvez garder privé.
3. Si une application d’authentification est demandée, suivez les instructions affichées. Saisissez le code de votre propre application et choisissez **Confirmer**.
4. Conservez les codes de récupération affichés avant de continuer. Si la page suivante demande d’enregistrer l’appareil ou d’attendre une approbation, suivez ses instructions.

## Et ensuite
Après les étapes de connexion et d’appareil requises, vous atteignez l’espace du personnel. Seules les tâches attribuées à votre compte peuvent apparaître. Une invitation ne donne pas accès à toutes les tâches de l’entreprise. Si le lien a expiré ou ne vous appartient pas, contactez la personne qui vous a invité plutôt que d’utiliser le compte d’un collègue.
