# Vixly.Operations.Resources

`.resx` text for the Operations plane in English, French and Spanish: error texts, enum labels, email and document text.

| | |
|---|---|
| Owner | Operations team |
| Build stage | 2 |
| May reference | Vixly.Shared.Kernel |
| Must not reference | Anything else. Referenced only by Operations Infrastructure, Api and Web; never by Domain or Application. |

Governed by the [Global Standard](../../../docs/global/VIXLY-GLOBAL-STANDARD.md) (section 5.5) and [ADR-0005](../../../docs/decisions/ADR-0005-multilingual-system.md). Not created as a project until its slice opens.
