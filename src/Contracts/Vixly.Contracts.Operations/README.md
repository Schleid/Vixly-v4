# Vixly.Contracts.Operations

Wire contracts of the Operations internal API (shipments, invoices, credit, tracking) for the Customer plane. Types prefixed `Operations` (e.g. `OperationsInvoiceDto`).

| | |
|---|---|
| Owner | Operations team with Customer team (joint sign-off) |
| Build stage | 2 |
| May reference | BCL only |
| Must not reference | Any other project; logic of any kind. |

Shapes are agreed by both teams before either side finishes. Additive changes only.

Governed by the [Global Standard](../../../docs/global/VIXLY-GLOBAL-STANDARD.md). Do not add code here until this project's stage opens.
