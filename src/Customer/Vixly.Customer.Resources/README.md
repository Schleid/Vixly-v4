# Vixly.Customer.Resources

`.resx` text for the Customer plane in English, French and Spanish: error texts, enum labels, portal text.

| | |
|---|---|
| Owner | Customer team |
| Build stage | 3 |
| May reference | Vixly.Shared.Kernel |
| Must not reference | Anything else. Referenced only by Customer Infrastructure and Web; never by Domain or Application. |

Governed by the [Global Standard](../../../docs/global/VIXLY-GLOBAL-STANDARD.md) (section 5.5) and [ADR-0005](../../../docs/decisions/ADR-0005-multilingual-system.md). Not created as a project until its slice opens.
