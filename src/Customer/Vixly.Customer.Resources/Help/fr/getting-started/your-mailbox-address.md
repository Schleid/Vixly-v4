Votre adresse de réception est celle fournie par {brandName} pour vos achats en ligne. Ce n’est ni votre domicile ni l’adresse de ce site. Votre code client permet d’identifier vos colis à leur arrivée à l’entrepôt.

Vous débutez ? La visite facultative présente l’adresse de réception, l’annonce de colis et l’expédition après votre profil. Ouvrez Aide et choisissez **Revoir la visite guidée** pour la revoir.

## Étapes
1. Connectez-vous et ouvrez **Ma boîte**. Repérez **Votre adresse de réception**.
2. Lisez votre code client et l’adresse complète affichée dessous.
3. Au paiement dans la boutique, utilisez cette adresse pour la livraison. Copiez exactement le destinataire, la rue, le complément, la ville, la région, le code postal et le pays. Conservez votre code client aux endroits où il figure.
4. Vérifiez l’adresse finale avant de payer la boutique. Ne remplacez pas la ville de l’entrepôt par celle de votre domicile. L’adresse de facturation est une question distincte.
5. Dès que la boutique ou le transporteur fournit le numéro de suivi du colis, annoncez celui-ci dans votre compte.

## Et ensuite
Si aucune adresse n’apparaît, contactez {brandName} avant de commander. Ne choisissez pas un autre entrepôt et n’inventez pas d’adresse. La livraison à l’adresse de réception est le premier trajet ; créer une expédition indique ensuite où envoyer les marchandises.

## Sur cet écran
1. Votre code client identifie votre compte.
2. Copiez cette adresse complète lors du paiement dans la boutique.
