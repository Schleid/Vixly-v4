# Inter variable font

Source: [official Inter publisher](https://rsms.me/inter/), downloaded 2026-10-16 from https://rsms.me/inter/font-files/InterVariable.woff2.

License: SIL Open Font License 1.1; see OFL.txt, retrieved from https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt. File retained without modification. The font is served locally by Shared.UI; pages do not contact a font CDN.

CSS uses font-display: swap, normal style, weights 100–900. Browser checks confirm the local WOFF2 resource loads and French/Spanish text renders. The existing system-font fallback remains available.
