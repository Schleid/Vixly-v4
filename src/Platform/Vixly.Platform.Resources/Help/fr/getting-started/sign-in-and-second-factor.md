Utilisez votre propre compte Vixly pour travailler dans Control. Gardez votre mot de passe, votre application d’authentification et vos codes de récupération privés. Ne partagez pas une session ouverte avec une autre personne, même pour une courte intervention.

Les écrans de connexion donnent leurs propres instructions. Effectuez la confirmation demandée avant de continuer. Si vous ne pouvez pas vous connecter, suivez les choix de récupération proposés ou contactez la personne responsable des accès du personnel.

## Étapes
1. Ouvrez **Mon compte** après la connexion. Vérifiez le profil pour vous assurer que vous utilisez le compte prévu.
2. Pour changer le mot de passe, renseignez **Mot de passe actuel**, **Nouveau mot de passe** et **Confirmez le nouveau mot de passe**. Choisissez **Changer le mot de passe**.
3. Consultez **Sessions ouvertes**. Fermez une session inconnue avec **Terminer**, ou utilisez **Se déconnecter sur tous les autres appareils** pour fermer vos autres sessions.
4. Sélectionnez votre **Langue de la console et de vos e-mails** préférée, puis choisissez **Enregistrer** pour changer la langue de la console.

## Et ensuite
Un changement de mot de passe ou la fermeture d’une session modifie l’accès. Vérifiez le message de résultat avant de continuer. Gardez la page ouverte jusqu’à la fin de l’action. Les passkeys et les nouveaux codes de récupération ont leur propre article.
