# Vixly.Platform.Resources

`.resx` text for the Platform plane in English, French and Spanish: error texts, enum labels, email and document text. Keys for errors equal the error code. No code beyond a marker type.

| | |
|---|---|
| Owner | Control team |
| Build stage | 1 (first created in Slice 1) |
| May reference | Vixly.Shared.Kernel |
| Must not reference | Anything else. Referenced only by Platform Infrastructure, Api and Web; never by Domain or Application. |

Governed by the [Global Standard](../../../docs/global/VIXLY-GLOBAL-STANDARD.md) (section 5.5) and [ADR-0005](../../../docs/decisions/ADR-0005-multilingual-system.md). Not created as a project until its slice opens.
