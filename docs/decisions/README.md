# docs/decisions

Architecture Decision Records. Any change to the Global Standard, any new `Vixly.Shared.Kernel` content, any breaking contract change, and any resolved open decision is recorded here as `ADR-NNNN-title.md` (see `ADR-TEMPLATE.md`).

Plane documents may add detail to the Global Standard but never contradict it; conflicts are resolved by ADR.

See the [Global Standard](../global/VIXLY-GLOBAL-STANDARD.md).
