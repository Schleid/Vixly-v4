# docs/shared

Shared.UI / Kernel documents: component catalogue conventions, gallery usage, verification record.

Component architecture is decided in [ADR-0001](../decisions/ADR-0001-component-architecture.md) and summarized in Global Standard 5.3. The gallery covers primitives only; feature components live in each plane's `*.Web` project.

Plane documents may add detail to the Global Standard but never contradict it; conflicts are resolved by ADR.

See the [Global Standard](../global/VIXLY-GLOBAL-STANDARD.md).
