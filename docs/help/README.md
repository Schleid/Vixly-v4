# docs/help

The plan for the help area inside each Vixly V4 application ([ADR-0023](../decisions/ADR-0023-in-app-help.md)).

Read in this order:

1. [HELP-PLAN](HELP-PLAN.md): what is built, the stages, the rules and the gate.
2. [HELP-0-FOUNDATION-DESIGN](HELP-0-FOUNDATION-DESIGN.md): article files and front matter, `Vixly.Shared.Help`, the checks, the pages and the reader rules.
3. [HELP-WRITING-GUIDE](HELP-WRITING-GUIDE.md): how to write an article.
4. The stage being built:
   - [HELP-1-PUBLIC](HELP-1-PUBLIC.md)
   - [HELP-2-CONTROL](HELP-2-CONTROL.md)
   - [HELP-3-CUSTOMER](HELP-3-CUSTOMER.md)
   - [HELP-4-OPERATIONS](HELP-4-OPERATIONS.md)

Verification records (`HELP-<n>-VERIFICATION.md`) are added here as each stage is completed.

These documents add detail to the [Global Standard](../global/VIXLY-GLOBAL-STANDARD.md) and never contradict it.
