Consulte estas respuestas cuando no pueda continuar el registro. Lea primero el mensaje de la página actual para distinguir un paso incompleto de un registro que ha terminado.

## Dirección del espacio y correo
Si el nombre de dirección está ocupado, elija otro con letras minúsculas, números y guiones. Su equipo y sus clientes usarán esta dirección: revísela antes de enviar.

Si no llega el correo de confirmación, compruebe la dirección parcialmente oculta del propietario y el correo no deseado. Use **Enviar el enlace de nuevo** para recibir otro mensaje. Si la dirección está equivocada, complete **Nueva dirección de correo electrónico** y seleccione **Cambiar el correo**. Vuelva a abrir el enlace completo si la página indica que está incompleto.

## Pago y finalización
Cancelar el pago no lo completa. Use **Ir al pago** cuando se muestre para volver a la factura. Un aviso de pago Zelle espera confirmación; comunicarlo no significa que la factura quede pagada inmediatamente.

La página de cuenta creada indica que se prepara el espacio y qué dirección recibirá el enlace de configuración. No permite cambiar un plan ya elegido. Contacte con el equipo si necesita revisar su suscripción.

## El registro está cerrado
Use una invitación válida para el correo del propietario o contacte con ventas. La ayuda sigue disponible durante el cierre; leerla no crea una cuenta ni reserva una dirección.
