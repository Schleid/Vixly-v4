Utilisez **Contact** pour parler de Vixly pour votre entreprise de logistique. Ce formulaire sert à échanger avec l’équipe sur votre activité, les forfaits ou le démarrage. Ce n’est pas l’espace de signalement des colis manquants utilisé par les clients d’une entreprise.

## Étapes
1. Renseignez **Entreprise**, **Votre nom** et **E-mail professionnel**. Utilisez une adresse où l’équipe peut vous joindre.
2. Ajoutez **Téléphone (facultatif)** si vous souhaitez fournir un numéro.
3. Choisissez la description la plus proche dans **Votre activité** : **Messagerie**, **Transport de fret**, **Entreposage**, **Logistique multi-sites**, **Autre**.
4. Décrivez votre besoin dans **Que souhaitez-vous améliorer ? (facultatif)**. Ce champ est facultatif. Concentrez la demande sur votre activité ; n’envoyez ni coordonnées de carte ni liens privés d’inscription.
5. Effectuez la vérification humaine et sélectionnez **Envoyer**.

## Ce qui se passe ensuite
Après un envoi réussi, la page affiche **Merci. Notre équipe vous contactera bientôt.**. Cela confirme l’envoi de la demande, pas la création d’un compte ou l’acceptation d’un forfait. L’équipe utilise vos coordonnées pour répondre.

La page présente aussi une adresse e-mail directe si vous préférez écrire. Si le formulaire affiche une erreur, lisez-la avant un nouvel envoi. Pour une inscription en cours, indiquez le nom de l’entreprise et l’étape atteinte.
