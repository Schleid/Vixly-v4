# tests/Shared

Test projects mirror the source projects one-to-one. Domain and Application tests are fast unit tests; Infrastructure tests are integration tests; authorization tests (role / scope / tenant matrix) are mandatory for every use case that enforces them.

Projects:

- `Vixly.Shared.Kernel.Tests`
- `Vixly.Shared.UI.Tests`

Governed by the [Global Standard](../../docs/global/VIXLY-GLOBAL-STANDARD.md).
