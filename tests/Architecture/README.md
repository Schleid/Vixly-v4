# tests/Architecture

Dependency-rule tests that fail the build when the Global Standard's reference rules are broken (layer direction, no cross-plane internals, Shared.UI purity, Contracts purity, entity-prefix naming). This project is the enforcement point; it is created in Stage 1 and extended each stage.
